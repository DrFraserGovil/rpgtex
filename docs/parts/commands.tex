	\section{Document Structure}\label{S:DocStructure}

		\rpgtex{} extends the standard \LaTeX{} commands for structuring a document. It provides title and part pages designed by the active theme, records the names of the current headings so that they may be reused elsewhere, and allows `fake' headings to be added to the table of contents.

		\begin{RpgSidebar}{The Title \& Sections Options}
			Much of the behaviour described in this section is provided by redefining standard \LaTeX{} commands, and is controlled by two package options \RpgPage[p]{S:PackageOptions}. Both are active by default when using one of the \rpgtex{} classes; otherwise, they must be passed to the package explicitly.
			\begin{description}
				\item[\texttt{title}] Redefines \cmd{maketitle} to produce the title designed by the active theme (equivalent to calling \cmd{RpgMakeTitle}). Otherwise, \cmd{maketitle} retains its original \LaTeX{} behaviour.
				\item[\texttt{sections}] Activates \emph{sections mode}, which:
				      \begin{itemize}
					      \item Redefines \cmd{chaptermark}, \cmd{sectionmark}, \cmd{subsectionmark} and \cmd{subsubsectionmark} so that, in addition to their usual behaviour, they store the name they are given \RpgPage[p]{S:SectionNames}.
					      \item Sets \texttt{secnumdepth} to \texttt{0}, so that sections and their subdivisions are unnumbered.
					      \item Replaces \cmd{part} with a version which records the part name and draws a full-page part page using the active theme. The starred form, \cmd{part*}, records the name but otherwise falls back to the original \LaTeX{} command.
				      \end{itemize}
				      Themes may additionally alter the formatting of the sectioning commands when sections mode is active.
			\end{description}
			All of the other commands in this section, including \cmd{RpgMakeTitle}, are available regardless of these options, although the stored heading names are only updated in sections mode.
		\end{RpgSidebar}

		\subsection{Title Pages}\label{S:TitlePages}

			The title page draws on the usual \cmd{title} and \cmd{author} commands, along with the following additions.

			\RpgFunction{subtitle}{\param{text}}
			{
				Sets the subtitle of the document. As with \cmd{title} and \cmd{author}, this has no visible effect by itself: the subtitle is displayed by \cmd{maketitle} if the theme includes it. The default value is empty.
			}
			\RpgFunction{cover}{\param{path/to/image}}
			{
				Sets an image to be used as the full-page background of the cover page created by \cmd{maketitle} in \texttt{cover} mode (see below). The theme's title design is drawn over the top of the image.

				The default value is empty, in which case the title design is drawn on a plain page.
			}
			\RpgFunction{RpgCoverTransparency}{\param{value}}
			{
				Fades the \cmd{cover} image towards white, which can help to keep the title legible over a busy image. The \texttt{value} is the opacity of a white layer placed over the image, between \texttt{0} (the image is unaltered) and \texttt{1} (the image is completely hidden). The default value is \texttt{0}.
			}
			\RpgFunction{maketitle}[RpgMakeTitle]{\param{}}
			{
				Creates the title of the document using the design provided by the theme (only when the \texttt{title} option is active; see above). There are two title modes:
				\begin{description}
					\item[\texttt{cover}] A full-page cover, drawn over the \cmd{cover} image (if one has been set). This is the default for the \texttt{rpgbook} class.
					\item[\texttt{header}] A title heading placed at the top of the first page of text.
				\end{description}
				The mode is selected with \cmd{RpgThemeTitleMode}\param{cover / header}. If the theme does not define a title for the active mode, the original \LaTeX{} \cmd{maketitle} is used instead.

				\cmd{RpgMakeTitle} is equivalent to \cmd{maketitle}, but remains available even if the \texttt{title} option is not active, or if another package redefines \cmd{maketitle}.

				\RpgGetExample{cmd-maketitle}
			}
			\RpgVariable{RpgGetTitle}[RpgGetTitle*]{The title set by \cmd{title}, formatted with the \cmd{RpgFontTitle} font element \RpgPage[p]{C:Fonts}. The starred form gives the title as plain text, without applying the font.}
			\RpgVariable{RpgGetSubtitle}[RpgGetSubtitle*]{The subtitle set by \cmd{subtitle}, formatted with the \cmd{RpgFontSubTitle} font element. The starred form gives the subtitle as plain text.}
			\RpgVariable{RpgGetAuthor}[RpgGetAuthor*]{The author set by \cmd{author}, formatted with the \cmd{RpgFontSubTitle} font element. The starred form gives the author as plain text.}

		\subsection{Part Pages}

			\RpgFunction{part}{(*)[<image>]\param{name}}
			{
				In sections mode \RpgPage[p]{S:DocStructure}, \cmd{part} is redefined to create a full-page part page using the design provided by the theme. Its behaviour depends on the form used:
				\begin{description}
					\item[{\texttt{\textbackslash{}part\{name\}}}] Adds the part to the table of contents and creates a part page on a plain background, or over the default part image if one has been set with \cmd{RpgDefaultPartImage}.
					\item[{\texttt{\textbackslash{}part[image]\{name\}}}] As above, but uses \texttt{image} as the full-page background.
					\item[{\texttt{\textbackslash{}part*\{name\}}}] Uses the original \cmd{part} command of the underlying class. Any image argument is ignored.
				\end{description}
				In all cases, \texttt{name} is recorded in \cmdref{RpgPartName}.
			}
			\RpgFunction{RpgDefaultPartImage}{\param{path/to/image}}
			{
				Sets an image to be used as the full-page background of every part page which is not given its own image. By default, no image is used.
			}
			\RpgFunction{RpgPartTransparency}{\param{value}}
			{
				Fades all subsequent images set by \cmd{part} image towards white, which can help to keep the text legible over a busy image. The \texttt{value} is the opacity of a white layer placed over the image, between \texttt{0} (the image is unaltered) and \texttt{1} (the image is completely hidden). The default value is \texttt{0}.
			}
		\subsection{Section Names}\label{S:SectionNames}
			Many RPG documents display the name of the current chapter or section outside of the heading itself -- in a running header, a footer, or a decorative page border, for example. To support this, \rpgtex{} records the names of the current part, chapter, section, subsection and subsubsection, so that they may be reused anywhere in the document.

			These names are only recorded in sections mode \RpgPage[p]{S:DocStructure}.


			Each of the following variables is initially blank, and holds its value until the next command of the same level is called: beginning a new chapter does not, for example, reset \cmd{RpgSectionName}.

			\RpgVariable{RpgPartName}{The name given to the last \cmd{part} or \cmd{part*} command.}
			\RpgVariable{RpgChapterName}{The name given to the last \cmd{chapter} command, or set by calling \cmd{chaptermark}. Starred chapters (\cmd{chapter*}) do not update this value.}
			\RpgVariable{RpgSectionName}{The name given to the last \cmd{section} command, or set by calling \cmd{sectionmark}. Starred sections (\cmd{section*}) do not update this value.}
			\RpgVariable{RpgSubsectionName}{The name given to the last \cmd{subsection} command, or set by calling \cmd{subsectionmark}. Starred subsections (\cmd{subsection*}) do not update this value.}
			\RpgVariable{RpgSubsubsectionName}{The name given to the last \cmd{subsubsection} command, or set by calling \cmd{subsubsectionmark}. Starred subsubsections (\cmd{subsubsection*}) do not update this value.}


			\RpgFunction{RpgGetName}{\param{part / chapter / section / subsection / subsubsection}}
			{
				Returns the name stored for the given level (equivalent to the corresponding variable above). Any other input results in an error.

				Since these names (other than that of the part) are taken from the \texttt{mark} commands, they may be set manually, without creating a new heading, by calling the relevant \texttt{mark} command directly.
				\RpgGetExample{section-names}
			}

		\subsection{Fake Sections}

			It can be helpful to be able to integrate common RPG elements (such as full page maps or images) into the document structure. The following command provides a simple interface for spoofing in a section (or part, chapter etc.) into the table of contents, without actually invoking a sectioning command:

			\RpgFunction{RpgFake}{\param{level}\param{name}}
			{
				Mimics the creation of a new heading at the given \texttt{level} without printing a heading in the document. Specifically, it:
				\begin{itemize}
					\item Adds an entry called \texttt{name} to the table of contents at the given level, with a hyperlink anchor at the current position.
					\item Updates the stored name for that level, as if a real heading had been created. For \texttt{chapter} to \texttt{subsubsection} this is done by calling the corresponding \texttt{mark} command, so any running headers are also updated.
				\end{itemize}
				The \texttt{level} must be one of \texttt{part}, \texttt{chapter}, \texttt{section}, \texttt{subsection} or \texttt{subsubsection}. Any other value results in an error.

				\RpgGetExample{fake-section}
			}
