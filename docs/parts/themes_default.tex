\chapter{\texttt{default} Theme}\label{Theme:Default}

	As the name suggests, the \texttt{default} theme is the theme which is loaded if no arguments are passed to \texttt{theme} when loading the \rpgtex{} package. As such, it is largely a re-statement of the default \LaTeX{} values. This is important, as most other themes begin by first re-inserting the default theme; thereby resetting everything into a `known state'. This means that they only need to define formatting which differs from the default.

	The majority of this document has been typeset in a rpgbook class \RpgPage[p]{S:bookClass} using the default theme.

		\subsection{Title \& Part Pages}\label{S:DefaultTitles}

			The title of a document is created by \cmdref{maketitle}, in one of two styles: a compact title or a cover page. The class chooses which is used \RpgPage[p]{C:Classes}, and a designer may change it with \cmdref{RpgThemeTitleMode}. The theme decides how each style looks.

			\subsubsection{Compact Title}

				The compact title is used by the \texttt{rpghandout} and \texttt{rpgdeck} classes. The default theme centres the title (in \FontRef{Title}) at the top of the page, followed by the subtitle and the author (both in \FontRef{SubTitle}). In a two-column document, the title spans both columns. Since the compact title is part of the text, it can be shown here:

				\RpgGetExample{theme-title-header}

			\subsubsection{Cover Page}

				The cover page is used by the \texttt{rpgbook} class. The default theme places the title, subtitle, author and date in a column at the centre of a page of their own, in the same fonts as the compact title. If a cover image has been set with \cmdref{cover}, it fills the page behind the text, faded according to \cmdref{RpgCoverTransparency}. The first page of this manual is a default-theme cover page, with a typewriter as its cover image.

			\subsubsection{Part Pages}

				In classes which have parts, such as \texttt{rpgbook}, \cmdref{part} produces a page of its own. The default theme places the word `Part' and the part's number in capitals, with the name of the part below, centred a little above the middle of the page, in \FontRef{Part}. An image may be placed behind the text, either for a single part (with the optional argument of \cmd{part}) or for every part (with \cmdref{RpgDefaultPartImage}), faded according to \cmdref{RpgPartTransparency}. The pages which begin each part of this manual are default-theme part pages.

				The cover and part pages of a short example document, typeset with the default theme, are:

	\section{RpgItems}\label{S:DefaultItem}

		The default theme gives \texttt{RpgItem} \RpgPage[p]{S:RuleEnvs} two properties:
		\begin{RpgTable}{lXl}
			Property & Effect & Default
			\\
			\texttt{description} & A short summary of the item, shown in italics beneath its name. & \textit{(none)}
			\\
			\texttt{image} & The path to an image of the item, shown beneath its name and description, at most 3cm tall. & \textit{(none)}
		\end{RpgTable}

	\section{RpgSpells \& RpgStats}\label{S:DefaultSpellStat}

		The default theme does not configure \texttt{RpgSpell} or \texttt{RpgStat} \RpgPage[p]{S:RuleEnvs}, since spells and statblocks depend so heavily on the rules of a particular game. They have no properties, and use the formats built into \rpgtex{}: the name is typeset as a \cmd{subsection}, followed by the body, both in text mode and on a card. Themes for a particular game, such as \texttt{dnd}, define their own.
