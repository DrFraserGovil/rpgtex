\chapter{\texttt{dnd} Theme}\label{Theme:dnd}

	The \texttt{dnd} theme is designed to mimic the appearance of the \textit{Dungeons \& Dragons} sourcebooks. Most of its design is derived from the original DnD-5e-LaTeX-Template package, with some additional updates in line with the 2024 rules. It begins by loading the default theme \RpgPage[p]{Theme:Default}, and so only changes the elements described below.

	\section{Appearance}
		\subsection{Fonts}

			If the \texttt{font} option is active, the \texttt{dnd} theme defines four font families, all of which are part of TeX Live:

			\RpgFunction{gillius}{\param{}}
			{
				{\gillius Gillius ADF No2}, a light sans-serif font, used for subtitles and for the body text of tables, tips, sidebars and narration.
			}
			\RpgFunction{gyreBonum}{\param{}}
			{
				{\gyreBonum TeX Gyre Bonum}, a Bookman-style serif font, used for the main body text and statblocks.
			}
			\RpgFunction{kepler}{\param{}}
			{
				{\kepler Kp Sans}, used for the titles of tables, tips and sidebars, statblock sections and part subtitles.
			}
			\RpgFunction{keplerserif}{\param{}}
			{
				{\keplerserif Kp Roman}, used in small capitals for headings, emphasis, card titles and the table of contents.
			}

			Drop capitals use the decorative {\Royal ROYAL} initials, from the \texttt{cfr-initials} package. The theme also creates two font elements of its own: \texttt{part-subtitle} (\cmd*{RpgFontPartSubtitle}), for the name of a part on its part page, and \texttt{stat-block-legendary} (\cmd*{RpgFontStatBlockLegendary}), for the explanatory text of a statblock's legendary actions.

			The values assigned to the font elements are as follows (note that \cmd{normalfont} is aliased to the value of \FontRef{Body}):

			\begingroup
			\FontTableElement{\RpgFontPartSubtitle}{part-subtitle}
			\FontTableElement{\RpgFontStatBlockLegendary}{stat-block-legendary}
			\InsertFontTable{}
			\endgroup

		\subsection{Colors}\label{S:DndColor}

			The \texttt{dnd} theme assigns the following values to the standard colors:

			\noindent\DefaultSwatches{}

			It also defines a number of colors of its own:

			\noindent\Swatch[paper]{Papyrus}
			\Swatch[footer \& page numbers]{FooterGold}
			\Swatch[titles \& contour inner]{TitleRed}
			\Swatch[title rules]{TitleGold}
			\Swatch[contour outer]{ContourGray}
			\Swatch[narration]{BrTan}
			\Swatch[statblock rules]{StatblockRule}
			\Swatch[statblock headings]{StatblockHeading}
			\Swatch[statblock frame]{StatblockFrame}
			\Swatch[statblock background]{StatblockBackground}
			\Swatch[legacy statblock borders]{StatblockRibbon}
			\Swatch[Basic Rules]{BrGreen}
			\Swatch[PHB Part 1]{PhbLightGreen}
			\Swatch[PHB Part 2]{PhbLightCyan}
			\Swatch[PHB Part 3]{PhbMauve}
			\Swatch[PHB Appendix]{PhbTan}
			\Swatch[DMG Part 1]{DmgLavender}
			\Swatch[DMG Part 2]{DmgCoral}
			\Swatch[DMG Part 3]{DmgSlateGray}
			\Swatch[DMG Appendix]{DmgPatina}

			The colors from \texttt{BrGreen} to \texttt{DmgPatina} match the tables and sidebars of the corresponding parts of the Basic Rules, the \textit{Player's Handbook} and the \textit{Dungeon Master's Guide} when set as the \texttt{ThemeColor} \RpgPage[p]{Cmd:RpgSetThemeColor}. Rather than setting them by hand, the theme steps through a cycle of these colors, moving to the next one at the start of each part, so that each part of a document has its own color. The following commands control the cycle:

			\RpgFunction{RpgAdvanceColors}{\param{}}
			{
				Moves to the next color in the cycle immediately, and sets it as the \texttt{ThemeColor}. This is called automatically at the start of each part.
			}
			\RpgFunction{RpgSetDMGColors}{\param{}}
			{
				Sets the cycle to the colors of the \textit{Dungeon Master's Guide}, followed by those of the \textit{Player's Handbook}, and moves to the first of them.
			}
			\RpgFunction{RpgSetPHBColors}{\param{}}
			{
				Sets the cycle to the colors of the \textit{Player's Handbook}, followed by those of the \textit{Dungeon Master's Guide}, and moves to the first of them. This is the cycle used by default.
			}
			\RpgFunction{RpgThemeSetColorCycle}{\param{colors}}
			{
				Sets the cycle to the comma-separated list of \texttt{colors}, and moves to the first of them.
			}

		\subsection{Backgrounds \& Footers}

			Each page is given a plain background in \texttt{Papyrus}, the \texttt{PaperColor} of the theme. A paper texture may be used instead:

			\RpgFunction{RpgSetDndPaper}{\param{}}
			{
				Sets the background of each subsequent page to the theme's paper texture image.
			}
			This effect is demonstrated on this page (and the subsequent pages of the dnd theme).
			\RpgSetDndPaper{}

			The footer is decorated with a scroll across the bottom of the page, which is mirrored on alternate pages in two-sided documents\footnote{This document is set to use the \texttt{oneside} option, so the footnotes do not alternate}. The name of the chapter is placed above the scroll, in \FontRef{Footer}, and the page number sits in a notch in the scroll, in \FontRef{PageNumber}.

		\subsection{Text Boxes}

			The \texttt{dnd} theme gives the text boxes the following appearance:

			\begin{multicols}{3}

				\begin{RpgSidebar}{The RpgSidebar}
					Horizontal `ribbons' and sharp corners differentiate it from RpgTip.
				\end{RpgSidebar}

				\begin{RpgTip}{The RpgTip}
					Almost entirely undecorated, with rounded corners.
				\end{RpgTip}

				\begin{RpgNarration}
					RpgNarration has red `bars' on either side, ending in dots.
				\end{RpgNarration}
			\end{multicols}

		\subsection{Title \& Part Pages}\label{S:DndTitles}

			The compact title is the same as in the default theme \RpgPage[p]{S:DefaultTitles}, but uses the fonts of the \texttt{dnd} theme:

			\RpgGetExample{theme-title-header}

			On the cover page, the title is outlined in white at the top of the page, above a glowing red diamond, and the subtitle and author are outlined at the bottom of the page.

			On a part page, the word `Part' and the part's number are placed in a badge at the top of the page, with the name of the part beneath it in \cmd*{RpgFontPartSubtitle}. The badge has two styles:

			\RpgFunction{RpgThemeSetDMGParts}{\param{}}
			{
				Draws the badge on subsequent part pages as a shield, in the style of the \textit{Dungeon Master's Guide}.
			}
			\RpgFunction{RpgThemeSetPHBParts}{\param{}}
			{
				Draws the badge on subsequent part pages as a semicircle, in the style of the \textit{Player's Handbook}. This is the style used by default.
			}

			The cover and part pages of a short example document, typeset with the \texttt{dnd} theme, are:
			\ThemePages{dnd}

		\subsection{Section Headers}

			As in the default theme, only parts and chapters are numbered. Headings are set in small capitals, in \texttt{TitleRed}. Chapter headings are outlined with \cmdref{RpgContour}, and subsection headings are underlined with a rule in \texttt{TitleGold}:

			\RpgGetExample{theme-section-headers}

		\subsection{Table of Contents}

			The table of contents is laid out as in the default theme \RpgPage[p]{Theme:Default}, but the entries for parts and chapters are set in small capitals, in \texttt{TitleRed}, and the rule beneath each part is in \texttt{TitleGold}.

	\section{RpgItems}\label{S:DndItem}

		The \texttt{dnd} theme gives \texttt{RpgItem} \RpgPage[p]{S:RuleEnvs} the following properties:
		\begin{RpgTable}{lXl}
			Property & Effect & Default
			\\
			\texttt{description} & A short summary of the item, shown in small capitals beneath its name in card mode, in place of its rarity and type. & \textit{(none)}
			\\
			\texttt{image} & The path to an image of the item, shown beneath its name in card mode, at most 3cm tall. & \textit{(none)}
			\\
			\texttt{rarity} & The rarity of the item, such as \texttt{Rare}. & \textit{(none)}
			\\
			\texttt{requires-attunement} & Whether the item requires attunement. Given as a flag, it adds `Requires attunement'; given a value, such as \texttt{by a paladin}, the value is added after it. & \texttt{none}
			\\
			\texttt{type} & The type of the item, such as \texttt{weapon (sword)} or \texttt{wondrous item}. & \textit{(none)}
		\end{RpgTable}

		In text mode, the name of the item is typeset as a \cmd{subsubsection}, followed by a line in italics giving its rarity, type and attunement, and then the body:

		\RpgGetExample{dnd-item-text}

		In card mode, which is turned on with \cmd{RpgSwitch}\param{UseItemCard}\param{on} \RpgPage[p]{Cmd:RpgSwitch}, the name is placed on a ribbon, which shrinks the text if it would not otherwise fit. The description (or the rarity and type) is placed above it, and the image, attunement and body below:

		\RpgGetExample{dnd-item-card}

	\section{RpgSpells}\label{S:DndSpell}

		The \texttt{dnd} theme gives \texttt{RpgSpell} \RpgPage[p]{S:RuleEnvs} the components of a D\&D spell as properties:
		\begin{RpgTable}{lXl}
			Property & Effect & Default
			\\
			\texttt{area} & The area of effect of the spell. If given, `Area of Effect' is shown in place of `Range', with the range in brackets after it. & \textit{(none)}
			\\
			\texttt{casting-time} & The time taken to cast the spell. & \texttt{1 action}
			\\
			\texttt{components} & The verbal, somatic and material components of the spell. & \texttt{VSM}
			\\
			\texttt{duration} & The duration of the spell. & \texttt{Instantaneous}
			\\
			\texttt{level} & The level of the spell, as a whole number. Level \texttt{0} is shown as a cantrip. & \texttt{0}
			\\
			\texttt{range} & The range of the spell. & \texttt{self}
			\\
			\texttt{school} & The school of magic of the spell, such as \texttt{Evocation}. & \textit{(none)}
			\\
			\texttt{source} & The book in which the spell is found. If given, it is shown after the other components. & \textit{(none)}
		\end{RpgTable}
		Any of these may contain a \cmd{footnote}, although only a single footnote may be used on a card \RpgPage[p]{Env:RpgCard}.

		In text mode, the name of the spell is typeset as a \cmd{subsubsection}, followed by its level and school in italics (such as `3rd level Evocation', or `Evocation Cantrip'), a list of its components, and the body:

		\RpgGetExample{dnd-spell-text}

		In card mode, which is turned on with \cmd{RpgSwitch}\param{UseSpellCard}\param{on} \RpgPage[p]{Cmd:RpgSwitch}, the level, school and name are placed at the top of the card, above a grid of the casting time, range, components and duration. The source is placed at the bottom of the card:

		\RpgGetExample{dnd-spell-card}

		The theme also provides two commands for the standard wording of D\&D spells:

		\RpgFunction{RpgCantripScaling}{[<name>]\param{1st}\param{5th}\param{11th}\param{17th}}
		{
			Typesets the sentence `This cantrip improves with your character level', followed by a table of the values of the cantrip at levels 1, 5, 11 and 17. The \texttt{name} labels the row of the table, and is \texttt{Damage} by default.
		}
		\RpgFunction{RpgSpellUpcast}{[<text>]\param{increase}[<levels>]}
		{
			Typesets the `At higher levels' paragraph of a spell: the \texttt{text} (`The damage increases by', by default), followed by the \texttt{increase} for every \texttt{levels} spell levels (\texttt{1}, by default) above the level of the spell. Since it uses the level of the current spell, it should only be used within an \texttt{RpgSpell}:

			\RpgGetExample{dnd-spell-upcast}
		}

	\section{Customising the \texttt{dnd} Theme}\label{S:DndDesigners}

		\begin{RpgSidebar}{You can ignore this section}
			This section is for those who wish to adjust the appearance or wording of the \texttt{dnd} theme, rather than to use it.
		\end{RpgSidebar}

		General changes can be made by using the exposed \cmd*{RpgTheme}\texttt{...} commands documented in Part~\ref{P:Designers}; for example modifying the font uses \cmdref{RpgThemeFont}.

		In addition to these general actions, the \texttt{dnd} theme exposes the following for \texttt{dnd}-specific modifications. Since loading the theme defines each of the following, any changes must be made after the theme is loaded, and are undone if it is loaded again with \cmdref{RpgSetTheme}.

		\subsection{Statblocks}

			\subsubsection{Colors}

				Every statblock is drawn in the following colors \RpgPage[p]{S:DndColor}, which may be redefined to change the appearance of all statblocks:
				\begin{RpgTable}{lX}
					Color & Used for
					\\ \texttt{StatblockRule} & The tapered rules. A pale shade of it is also used as the \texttt{ThemeColor} within the statblock, and so for its tables.
					\\ \texttt{StatblockHeading} & The title, the section headings, and the text of the header block (from the armor class to the challenge rating).
					\\ \texttt{StatblockFrame} & The frame, and the filigree of \texttt{filigree-match}.
					\\ \texttt{StatblockBackground} & The background, unless the \texttt{background} option is off, when it is white.
					\\ \texttt{StatblockRibbon} & The borders at the top and bottom, in the legacy appearance \RpgPage[p]{S:DndStatLegacy}.
				\end{RpgTable}
				Since \cmd{colorlet} copies a color at the moment it is used, a color defined in terms of another (such as \texttt{StatblockHeading}, which is a dark shade of \texttt{StatblockRule}) does not change when the other is redefined: each must be redefined separately. The \texttt{color} and \texttt{frame-color} properties \RpgPage[p]{S:DndStatAppearance} override these colors within a single statblock.

			\subsubsection{The Frame}

				Each statblock (outside of card mode) is framed by a \texttt{tcolorbox}, whose appearance is held in the \texttt{rpgstatbox} style. It may be adjusted in the same way as the styles of the other boxes \RpgPage[p]{S:ElementStyles}; for example,
				\begin{center}
					\cmd*{tcbset}\{rpgstatbox/.append style=\{sharp corners\}\}
				\end{center}
				removes the rounded corners of every statblock which follows. \cmdref{RpgStatLegacyMode} replaces the style with the legacy appearance, so any changes should be made after it is called.

			\subsubsection{Rules}

				The tapered rules which separate the parts of a statblock are drawn by:

				\RpgFunction{RpgStatLine}{\param{}}
				{
					Draws a tapered rule across the width of the line, in \texttt{StatblockRule}. It may also be used outside of a statblock.
				}

		\subsection{Part Pages}

			\RpgFunction{RpgThemePartPageTikz}{\param{}}
			{
				Draws the badge at the top of each part page \RpgPage[p]{S:DndTitles}, which is placed with its top at the top edge of the page, and centred. It may be redefined (for example, with \cmd{RenewDocumentCommand}) to draw a different badge. \cmdref{RpgThemeSetDMGParts} and \cmdref{RpgThemeSetPHBParts} work by redefining it, and so replace any custom badge.
			}

		\subsection{Wording}

			The fixed text of the legendary and mythic sections \RpgPage[p]{S:Legendary} is held in the following commands, which may be redefined with \cmd{renewcommand} (for example, to translate them). Within them, \cmdref{RpgStatName} gives the name of the creature.

			\RpgVariable{rpgstringlegendaryDefiance}
			{
				The description of the homebrew `Legendary Defiance' action.
			}
			\RpgVariable{rpgstringlegendaryResistance}
			{
				The description of the `Legendary Resistance' trait.
			}
			\RpgVariable{rpgstringlegendarySpiel}
			{
				The explanation of legendary actions, which begins the `Legendary Actions' section.
			}
			\RpgVariable{rpgstringmythicDefaultBody}
			{
				The default description of the mythic trait, used if no \texttt{trait} is given to \cmdref{RpgStatMythicSection}.
			}
			\RpgVariable{rpgstringmythicGains}
			{
				The sentence which introduces the traits a creature gains when its mythic trait activates.
			}
			\RpgVariable{rpgstringmythicNarrationLeadIn}
			{
				The sentence which introduces the \texttt{narration} of \cmdref{RpgStatMythicSection}.
			}
