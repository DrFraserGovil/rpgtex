\chapter{Installing \rpgtex{}}

	\section{Getting \rpgtex}

		\rpgtex{} may be installed in several ways, described below. The package dependencies can be found in Appendix \ref{C:Dependencies} \RpgPage[p]{C:Dependencies}. Once installed, \rpgtex{} attempts to locate its internal resources (fonts and images) automatically. If this fails, manual configuration may be required, see \RpgPage[t]{S:Configuration}.


		\begin{RpgSidebar}{Operating Systems}

			The commands below are written assuming a Linux or macOS terminal.  Windows users should consult the section on \RpgPage[t]{S:Windows} for more information.
		\end{RpgSidebar}


		\subsection{Direct Installation}

			The simplest approach is to install \rpgtex{} on the \texttt{texmf} path, where the compiler will find it automatically:

			%\begin{noindent}
			\begin{BashBlock}
				mkdir -p "$(kpsewhich -var-value TEXMFHOME)/tex/latex" # make sure the directory exists
git clone https://github.com/DrFraserGovil/rpgtex.git "$(kpsewhich -var-value TEXMFHOME)/tex/latex/rpgtex"
			\end{BashBlock}
			%\end{noindent}
			This clones the repository into your personal \LaTeX{} directory, which is typically \texttt{\textasciitilde/texmf} on Linux, \texttt{\textasciitilde/Library/texmf} on macOS, and \texttt{C:\textbackslash{}Users\textbackslash{}<username>\textbackslash{}texmf} on Windows.


		\subsection{Indirect Installation}

			If you intend to modify \rpgtex{} -- for example, by creating a new theme -- it is more convenient to keep it somewhere easily accessible. First, clone the repository into a location of your choice:

			\begin{BashBlock}
				git clone https://github.com/DrFraserGovil/rpgtex.git ~/path/to/rpgtex
			\end{BashBlock}

			The package must then be made visible to the compiler, in one of two ways.

			\subsubsection{Using TEXINPUTS}

				The \texttt{TEXINPUTS} environment variable adds directories to the compiler's search path. The \texttt{//} includes all subdirectories of the given directory, and the trailing colon keeps the standard search locations:
				\begin{BashBlock}
					export TEXINPUTS=~/path/to/rpgtex//:
				\end{BashBlock}
				The exact command depends on your shell; add it to your shell's configuration file to make it permanent.

			\subsubsection{Using a Symbolic Link}

				Alternatively, a symbolic link from the \texttt{texmf} directory to the repository allows the compiler to behave exactly as if \rpgtex{} had been installed directly:

				%\begin{noindent}
				\begin{BashBlock}
					mkdir -p "$(kpsewhich -var-value TEXMFHOME)/tex/latex"
ln -sf ~/path/to/rpgtex "$(kpsewhich -var-value TEXMFHOME)/tex/latex/rpgtex"
				\end{BashBlock}
				%\end{noindent}

		\subsection{Windows}\label{S:Windows}

			\rpgtex{} works on Windows, with a few differences from the instructions above:
			% HACK: we also don't know if MiKTeX actually works yet
			\begin{itemize}
				\item Run the git commands using Git Bash for Windows
				\item Use the direct installation. Symbolic links and \texttt{TEXINPUTS} behave differently on Windows, and are best avoided.
				\item If you use MiKTeX, it does not automatically detect new files in its directories. After installing, register the folder containing \rpgtex{} as a root directory in MiKTeX Console (if it is not already one), and then refresh the file name database (\textit{Tasks} $\rightarrow$ \textit{Refresh file name database}). TeX Live requires no extra steps.
				\item Run the provided Python scripts through Python explicitly, for example \texttt{python rpglatex document.tex}.
			\end{itemize}

	\section{Compiling \rpgtex{} Documents}\label{C:Compiler}

		\rpgtex{} uses the \texttt{fontspec} package to load its fonts, and so must be compiled with \texttt{xelatex} or \texttt{lualatex} in almost all cases. An exception is if \rpgtex{} is loaded as a package without the font option \RpgPage[p]{flag:font}:
		\begin{Code}
			xelatex main.tex   \# works

			lualatex main.tex  \# works

			pdflatex main.tex  \# fails when the font option is active
		\end{Code}


		\subsection{Path Configuration} \label{S:Configuration}

			In most cases, no further steps are required to compile a document, since \rpgtex{} finds its own installation path, and stores the value in the following variable:

			\RpgVariable{RpgPackagePath}{The path to the root directory of the \rpgtex{} installation. \rpgtex{} uses it to load resources, such as fonts, which \TeX{} cannot find relative to the package itself. It is set by the first of the following which is available:
				\begin{enumerate}
					\item \textbf{The \texttt{rpglatex} compiler} \RpgPage[p]{S:rpglatex}, which defines it before the document is read.
					\item \textbf{A configuration file}, \texttt{core/rpg-config.cfg}, within the installation
					\item \textbf{Automatically.} \rpgtex{} asks \texttt{kpsewhich} where \texttt{rpgtex.sty} is installed. This uses the compiler's restricted shell escape, which TeX Live enables by default, so no extra flags are needed.
				\end{enumerate}
				If none of these succeeds, compilation stops with an error describing these options.
			}

			\subsubsection{Failed Configuration}
				Most users will rely on the third option, the automatic configuration. However, this may fail if \LaTeX{} is (for example) running in safe mode. In such cases the user must either use the \texttt{rpgtex} compiler, run the python script located at \texttt{scripts/configure-rpgtex}, or manually create the configuration file:

				\begin{Code}
					cd <rpgtex root directory>

					echo '\cmd*{edef}\cmd*{RpgPackagePath}\{'"\$(pwd)"'\}' > core/rpg-config.cfg
				\end{Code}
				If \rpgtex{} is later moved, the file must be deleted or recreated.
