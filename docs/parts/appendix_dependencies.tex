\chapter{Dependencies}\label{C:Dependencies}

	\rpgtex{} loads the packages listed below. All of them are included in a full TeX Live installation, and MiKTeX installs missing packages automatically the first time they are needed. On a minimal installation, missing packages may be added with \texttt{tlmgr}:
	\begin{BashBlock}
		tlmgr install <package>
	\end{BashBlock}
	Some files are distributed as part of a larger package, whose name must be given to \texttt{tlmgr} instead; this name is shown in brackets. Packages marked with an asterisk are only loaded in some circumstances, which are described beneath the list.

	The packages marked with an asterisk are loaded as follows:
	\begin{itemize}
		\item \texttt{fontenc} and \texttt{fontspec}: when the \texttt{font} option is active \RpgPage[p]{S:PackageOptions}.
		\item \texttt{geometry}: by the \rpgtex{} classes.
		\item \texttt{luacolor}: when compiling with \texttt{lualatex}.
		\item \texttt{multitoc}: by the \rpgtex{} classes, unless the \texttt{nomultitoc} option is used.
		\item \texttt{standalone}: by the \texttt{rpgcard} and \texttt{rpgdeck} classes.
	\end{itemize}
	In addition, the classes are built on the standard \texttt{book} and \texttt{article} classes, which are part of every \LaTeX{} installation, as is \texttt{expl3}.

	\section{Fonts}

		The \texttt{default} and \texttt{dnd} themes use fonts from the \TeX{} distribution, while the fonts of the \texttt{scifi} theme are distributed with \rpgtex{} itself, in \texttt{themes/scifi/fonts}. Fonts are only loaded when the \texttt{font} option is active. The \texttt{default} theme uses Latin Modern, which is part of every \TeX{} distribution; the \texttt{dnd} theme uses:
		\begin{itemize}
			\item \texttt{texgyrebonum-*.otf} (\texttt{tex-gyre}): TeX Gyre Bonum, the main body font.
			\item \texttt{EBGaramond-Regular.otf} (\texttt{ebgaramond}): EB Garamond, used for small capitals.
			\item \texttt{KpSans-*.otf} and \texttt{KpRoman-*.otf} (\texttt{kpfonts-otf}): Kp-Fonts, used for titles and table headings.
			\item \texttt{GilliusADFNo2-*.otf} (\texttt{gillius}): Gillius ADF No2, used for subtitles and table text.
		\end{itemize}
