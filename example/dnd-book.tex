		\section{Appearance}

			\subsection{Colors}

				In addition to a host of defined colours, the D\&D theme uses a 'colorcycle' mechanic to change the underlying ThemeColor each time a \cmd{part} begins (or the user calls \cmd{RpgAdvanceColors}). This means tables, sidebars and any other element keyed off the Theme Colour will have a unique appearance in each part.

				\begin{RpgTip}{Before...}
					This is the 'original' appearance
				\end{RpgTip}
				Then call \cmd{RpgAdvanceColors}...\RpgAdvanceColors{}
				\begin{RpgTip}{After...}
					This is the next colour in the cycle
				\end{RpgTip}

				\subsubsection{Customising Color Cycles}
					The color cycle can be set by calling \cmd{RpgThemeSetColorCycle\{a,b,c,...\}}, and if the items in the list are valid colours, this will replace the current colour cycle.

				\subsubsection{Inbuilt Cycles}
					We provide two inbuilt cycles\footnote{Actually, they're the same cycle, but starting at different points}, which can be activated with the following commands:
					\begin{description}
						\item[\cmd{RpgSetPHBColors}] Initialises colors which mimic the 2014 Player's Handbook parts. This is the default color cycle.
						\item[\cmd{RpgSetDMGColors}] Colors which mimic the 2014 Dungeon Master's Guide parts.
					\end{description}

					Calling this commands also has the effect of resetting the cycle back to the beginning.

					\RpgSetPHBColors{}
			\subsection{Dice Formatting}
				The \cmd{RpgDice} command is set to format dice expressions in the way used in the Monster Manual; providing the average result of the roll (rounded down). It is also configured to convert `dX' into `1dX:
				\begin{RpgTable}{lX}
					Expression & Result
					\\
					\cmd{RpgDice\{1d6 + 3\}} & \RpgDice{1d6 + 3}
					\\
					\cmd{RpgDice\{2d10 + 3 - 2*7\}} & \RpgDice{2d10 +3 - 2*7}
					\\
					\cmd{RpgDice\{d4\}} & \RpgDice{d4}
				\end{RpgTable}

		\section{Rule Environments}

			The D\&D theme makes heavy use of all of the `Rule Environments' to produce consistently formatting blocks for Items, Spells, Feats and Monsters.





			\begin{RpgTip}{Some Example Spells}
				\begin{RpgSpell}{Compile Document}[
						level=3,
						school=Conjuration,
						range=within 60ft,
						area=30ft cube,
						components={VS}
					]
					Roll 1d4, a number of documents equal to this number within the area are converted to \textit{Powerful Dragon Format}, which has its own initiative and considers you an ally. For each dragon converted in this fashion, you regain 5 hit points.

					\RpgSpellUpcast[The hitpoints restored by each dragon increase by]{5}
				\end{RpgSpell}

				\begin{RpgSpell}{Faulty Preamble}[
						school=Evocation,
						range=touch,
						duration={Until Dispelled},

					You corrupt a document that you touch. When this document is affected by \textit{Compile Document}, it does not convert into a Powerful Dragon Format, and instead deals \RpgDice{1d10} psychic damage to the individual attempting the compilation.

					\RpgCantripScaling{1d10}{2d10}{3d10}{4d10}

				\end{RpgSpell}
			\end{RpgTip}

			\subsubsection{Legacy Statblocks}

				The default statblock uses a format similar to the modern 2024 statblock design (with a few streamlining tweaks of our own).

				It is possible to switch back to the original 2014 appearance, by calling  \cmd{RpgStatLegacyMode}. This replaces the outer box and tweaks the way that the stats are presented.
