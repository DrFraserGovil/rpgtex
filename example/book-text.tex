\chapter{The RpgTeX Basics}


	\RpgDropCap{H}{ello and welcome!} This package is designed to aid you in writing beautifully typeset documents for a variety of RPG documents. It is derived from {a D\&D-specific package}\footnote{\url{https://github.com/rpgtex/DND-5e-LaTeX-Template}}, but whilst we have retained much of the internal engine, we have adapted it to work with a variety of themes, thus making it a system-agnostic \verb|rpgtex|.

	This document is \textbf{not} intended to be the full documentation - merely a quick showcase.

	\section{Fonts}

		This document demonstrates a number of the fonts which have been automatically loaded by the chosen theme.

		\subsection{Emphasis}

			Unless the \texttt{noemph} option is passed, the \cmd{emph} command is altered to mirror the \cmd{RpgKey} command, this produces a distinctive \emph{keyword emphasis}.

	\section{Paper \& Background}

		The chosen theme automatically applies `paper effects' such as decorations and a background color, which you can see throughout this document.

		This can be disabled by loading the documentclass with the \texttt{print} key (which disables the background coloration but leaves any footer decorations), or the \texttt{none} key, which disables all visual effects.

	\section{Sectioning}
		Sections follow the standard \LaTeX{} formatting; with the \cmd{chapter} command demonstrated at the top of the page, and \cmd{section} above this paragraph. The other sectioning commands are demonstrated below.

		\subsection{Subsection}

			We can use subsections to further break up text.

			\subsubsection{Subsubsection}

				Subsubsections are the smallest level that get an out-of-line header.

				\paragraph{Paragraph} A paragraph block lets you highlight something inline.

				\subparagraph{Subparagraph} Subparagraphs are formatted like this.

	\section{Image Pages}
		The RpgTeX package provides a convenient interface to fill an entire page with an image. This can be invoked manually (\cmd{RpgFullPageImage}), and forms the basis for the Title and Part pages.

		\subsection{Title Pages}
			You can see the formatting of the default cover page on Page 1. If the user supplies a \cmd{cover} (as they would a \cmd{title} or an \cmd{author}), the \cmd{maketitle} command has been altered to allow this to be used as the path to the background image.

			A transparency effect can also be applied using \cmd{RpgCoverTransparency\{x\}} before \cmd{maketitle} is called - with 0 being the normal image, and 1 being a white page. The cover image of this document uses a value of 0.5.

		\subsection{Parts}

			In classes where \cmd{part} is available, a similar effect is possible. In this case, the user passes the image as an optional argument; \cmd{part[image/path]\{Part Title\}}.

			The transparency effect can be set by \cmd{RpgPartTransparency} which effects all part-pages going forwards. An example of a part page is shown below.
	\section{Tables}

		RPGs rely on tables to display information, so having nicely formatted tables is essential: the \texttt{RpgTable} environment is your friend.

		\begin{RpgTable}{l X}
			d6 & Effect
			\\
			1 & You accidentally call \texttt{rm -rf --no-preserve-root}
			\\
			2 & Your document fails to compile with an error message no-one has ever seen before
			\\
			3 & Your document fails to compile, but you recognise the error message.
			\\
			4 & You mispelled \cmd{textit} as \cmd{tetxit} \textit{again}
			\\
			5 & Your document compiles with no errors
			\\
			6 & Your document compiles \textit{and} a cat comes and sits on your lap
		\end{RpgTable}

		This automatically applies the header formatting, and the alternating row colors. The tables inherit from \texttt{tabularx} allowing the X-column (demonstrated above), as well as the Y-column (a centered variant of X).

	\section{Callouts}
		We provide three separate callout boxes, which mainly differ in their default formatting (and if they take a title or not).

		\begin{RpgTip}{A Helpful Tip}
			The \texttt{RpgTip} environmenmt is used to give helpful tips or tricks to the reader.
		\end{RpgTip}

		\begin{RpgSidebar}[]{Pay Attention to Sidebars!}
			Sidebars are useful for highlighting information the reader must pay attention to.
		\end{RpgSidebar}
		\begin{RpgNarration}
			As you read this document, you realise that this is a \texttt{RpgNarration}, a callout without a title designed to indicate text that the game master will read out loud to the players.
		\end{RpgNarration}

	\section{Filigree}

		We also provide the \texttt{RpgFiligree} environment, which provides a decorated callout for arbitrary input:

		\begin{RpgFiligree}[opacityback=0.3]
			\begin{RpgTable}{lX}
				Title & Contents
				\\
				A & Some text that is very nicely decorated
			\end{RpgTable}
		\end{RpgFiligree}

		Callouts also accept the \texttt{filigree} argument to automatically decoated them:
		\begin{RpgSidebar}[filigree]{Pay Attention to Sidebars!}
			Especially when they have pretty filigree decorating them!
		\end{RpgSidebar}
	\section{Maps}

		It is often useful to provide a structured way to label the regions on a map that the players are exploring. The \texttt{RpgMap} provides an itemise-like environment for providing nested descriptions of regions.

		Each area can be labelled using optional arguments, and then referred to either with \cmd{ref} or the provided \cmd{RpgMapRef} (which returns the area name, not just the number)

		\begin{RpgMap}[title={Mysterious House},header-offset=2]
			This is a mysterious area that needs to be explored by brave(?) individuals.
			\area{Entryway} Cobwebs drape everything. Doors leading to areas \ref{kitchen} and \ref{basement} branch off. A secret passage to area \ref{treasure} can only be accessed by saying a special incantation.

			\area[kitchen]{Kitchen} There is a hole in the floor through which area \RpgMapRef*{wine} can be seen.

			\begin{RpgArea}[basement]{Basement}
				This large area is split up into several smaller blocks
				\area[wine]{Wine Rack} Some lovely vintages here.
				\begin{RpgArea}{Subbasement}
					Even more areas are nested here
					\area{Murder Room} We all have one of these downstairs. Nothing to see here!
				\end{RpgArea}
			\end{RpgArea}

			\area[treasure]{Treasure Room} Wow, there's so much treasure in here!
		\end{RpgMap}

	\section{Secrets}

		It can often be useful for a game master to keep secret notes on a document that might be shared with players. Rather than maintaining two documents, they can use the \texttt{RpgSecret} environment: so long as they only share the final PDF with players, the secret can be toggled in and out of view.

		\subsection{Switched Off}
			With \cmd{RpgSwith\{ShowSecrets\}\{off\}}, the block will appear as:

			\RpgSwitch{ShowSecrets}{off}
			\begin{RpgSecret}{This is some text that the players read, lah-de-dah, no secrets here! I love the intricate story my game master has woven for me!}
				Oh but wait, there's a secret here! The players don't know that secretly I am making this all up as I go along!
			\end{RpgSecret}
		\subsection{Switched On}
			With \cmd{RpgSwith\{ShowSecrets\}\{on\}}, the same block of code will appear as:

			\RpgSwitch{ShowSecrets}{on}
			\begin{RpgSecret}{This is some text that the players read, lah-de-dah, no secrets here! I love the intricate story my game master has woven for me!}
				Oh but wait, there's a secret here! The players don't know that secretly I am making this all up as I go along!
			\end{RpgSecret}
